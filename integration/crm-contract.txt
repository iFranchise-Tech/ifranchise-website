Build iFranchise CRM web app / sites/ifranchise-crm/lib/crm/acquisition.mjs
and public/ifranchise-enquiry.mjs, lib/crm/conversions.mjs, lib/crm/tagging.mjs.
The existing CRM is Vinext/React on Sites with Cloudflare D1 and a separate public intake relay.

Existing gateway contract supported by lib/enquiry.mjs:
GET  {relayOrigin}/forms/{formId} returns approved notice, Turnstile public key, form version, optional reviewed tagging configuration.
POST {relayOrigin}/forms/{formId}/session with {} returns a short-lived token.
POST {relayOrigin}/forms/{formId}/submit with:
  token, name, phone, email, city, contact_permission, challenge,
  website (empty honeypot), source, advertising_permission, tagging_version.
source supports utm_source, utm_medium, utm_campaign, utm_content, utm_term,
gclid, gbraid, wbraid, fbclid, li_fat_id.
The website sends only allowlisted values (max 512 chars), only with advertising consent.
The browser keeps consented first/last campaign touch for the session; the current API receives the last available campaign. Full first/last touch, initial landing page and CRM qualification fields require an API extension.
The CRM binds brand/model to the form configuration, checks exact Origin,
validates Turnstile with action crm_enquiry, checks contact consent,
normalizes identity, deduplicates, and owns the authoritative receipt.
Only received:true + event_id is success. advertising_event_allowed controls conversion emission.
Retries reuse the session token. The CRM disables advertising on replay.
